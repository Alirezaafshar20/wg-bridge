# راهنمای ضبط آموزش WG Bridge 0.4

1. معرفی: ساخته‌شده توسط alirezaw؛ پنل و کاربران روی ایران می‌مانند و خروجی انتخاب‌شده از تونل WireGuard به اینترنت خارج می‌رسد.
2. تفاوت پورت‌ها: 9999/UDP پیش‌فرض ارتباط دو سرور است؛ اینباندهای کاربران می‌توانند پورت‌های متفاوت داشته باشند. در این روش پورت سرویس خارج یا SOCKS نداریم.
3. برای ویدیوی نصب از صفر، از سرورهای آزمایشی بدون نصب قبلی استفاده کنید. برای نسخه 0.3، ارتقا و دستور routing را در بخش جداگانه نشان دهید؛ خارج اول و سپس ایران. نصب مجدد روی نسخه موجود منوی مدیریت را باز می‌کند.
4. Requirements و سپس تک‌دستور Install را از README اجرا کنید. پورت UDP انتخاب‌شده روی فایروال ارائه‌دهنده هر دو سرور باز باشد.
5. خارج: گزینه 2، IP خارج، پورت WireGuard، IP ایران و پورت WireGuard ایران. توضیح دهید Enter پیش‌فرض رنگی را می‌پذیرد.
6. هنگام نمایش، کپی و پیست WGB3 ضبط را متوقف یا کد را کامل بپوشانید؛ کد کلید خصوصی دارد و هنگام پیست دیده می‌شود.
7. ایران: گزینه 1، کد کامل و تأیید IP و پورت. `wg-bridge doctor` باید handshake، HTTPS با IP خارج و DNS با UDP را تأیید کند.
8. پنل ثنایی را روی ایران نصب کنید. طبق [راهنمای پنل](panels.fa.md)، خروجی freedom با تگ wg-out، Send Through برابر 10.204.0.2 و Interface برابر wgb-exit بسازید. نمونه JSON تنظیم ForceIPv4 را هم نشان دهید.
9. DNS داخلی پنل و قانون wg-dns را طبق راهنما تنظیم کنید. سپس تگ واقعی اینباندهای کاربران را به wg-out هدایت کنید. قانون api و قوانین مسدودسازی باقی بمانند. پورت مقصد در Routing جایگزین انتخاب inboundTag نیست.
10. ذخیره و اعمال تغییرات پنل؛ با یک کلاینت واقعی وصل شوید و IP خروجی خارج، بازشدن دامنه و برنامه UDP را نشان دهید. موفقیت doctor جای آزمون کاربر واقعی را نمی‌گیرد.
11. منو با `wg-bridge` باز می‌شود؛ دستور نصب دوباره لازم نیست. تونل را کوتاه متوقف کنید: اینترنت کاربر منتخب باید قطع شود، ولی SSH و اینترنت خود ایران باقی بمانند. تونل را دوباره شروع کنید.
12. توضیح حدود پشتیبانی: خروجی IPv4، پنل روی شبکه میزبان، یک جفت سرور در هر نصب؛ ظرفیت به منابع و شبکه بستگی دارد. اشتراک نام کلید یا تغییر پورت، محدودیت شبکه را تضمینی رفع نمی‌کند.
13. روش حذف: `wg-bridge uninstall` و تأیید REMOVE؛ خروجی پنل نیز باید دستی حذف یا غیرفعال شود. حذف کلیدها را روی سرور تولیدی برای نمایش انجام ندهید.
