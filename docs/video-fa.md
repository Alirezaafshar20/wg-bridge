# طرح ویدیوی نصب WG Bridge

1. معرفی: ساخته‌شده توسط alirezaw؛ انتقال یک پورت ایران به سرویس روی خارج با WireGuard.
2. نمایش مسیر با مثال `Iran:8443 → WireGuard → Outside:8443`؛ توضیح دهید سرویس مقصد روی خارج است و اینترنت عمومی ایران وارد تانل نمی‌شود.
3. اگر نسخهٔ 0.1 یا 0.2 نصب است، ابتدا مراحل انتقال در README فارسی را انجام دهید: توقف هر دو سرویس روی ایران، حذف تانل قبلی روی هر دو میزبان، نصب جدید.
4. دستور Requirements و سپس دستور Install را از README اجرا کنید.
5. روی خارج گزینهٔ 2، IP خارج و UDP وایرگارد (پیش‌فرض 9999) را تعیین کنید. سپس IP عمومی ایران و پورت UDP موردنظر روی ایران را وارد کنید؛ مقدار پیش‌فرض همان پورت خارج است. این اطلاعات برای آغاز اتصال از هر دو سمت است. پورت جداگانهٔ سرویس و TCP/UDP/both را انتخاب کنید؛ برنامهٔ مقصد باید روی همهٔ آدرس‌ها یا IP خصوصی تانل گوش کند.
6. هنگام نمایش یا کپی کد WGB2 ضبط را متوقف کنید؛ کد حاوی کلید خصوصی است.
7. روی ایران گزینهٔ 1 و کد کامل را وارد کنید؛ IP و پورت UDP ایران باید با مقادیر تعیین‌شده روی خارج تطبیق داشته باشند. پورت ورودی دلخواه سرویس را انتخاب کنید. کد هنگام واردکردن قابل‌مشاهده است؛ این بخش را ضبط نکنید.
8. از دستگاه سوم به پورت انتخابی ایران متصل شوید. دستور `wg-bridge doctor` اتصال WG و در صورت انتخاب TCP، دسترسی به سرویس مقصد را بررسی می‌کند؛ UDP نیازمند تست با برنامهٔ واقعی است.
9. عبارت Press Enter to use و رنگ متفاوت پیش‌فرض‌ها را توضیح دهید. پیش‌فرض UDP خود WireGuard برابر 9999 است؛ پورت سرویس پیشنهاد آزاد تصادفی دارد و هر دو قابل تغییرند. UDP وایرگارد باید روی هر دو فایروال ارائه‌دهنده باز باشد. منو با `wg-bridge` باز می‌شود؛ تغییر پورت سرویس ایران با `wg-bridge port 9443` و تنظیم آدرس و پورت WireGuard ایران از گزینهٔ 8 منوی خارج انجام می‌شود.
10. تانل را متوقف کنید: فقط پورت منتقل‌شده باید از کار بیفتد؛ دانلود، پینگ و سرویس‌های دیگر ایران را جداگانه بررسی کنید. سپس تانل را شروع کنید.
11. حذف با `wg-bridge uninstall` و تأیید `REMOVE`؛ این مرحله کلیدهای تانل را حذف می‌کند.

`NO HANDSHAKE` به معنی برقرارنشدن WireGuard است. پورت سرویس با پورت UDP خود WireGuard فرق دارد؛ بازبودن مسیر UDP و فایروال ارائه‌دهنده را بررسی کنید.
